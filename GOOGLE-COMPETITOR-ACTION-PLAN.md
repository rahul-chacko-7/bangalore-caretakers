# Google and Competitor Action Plan

## 0–7 days: remove ranking risk

1. Confirm `bangalorecaretakers.in` as the only indexable property in Search Console and submit `/sitemap.xml`.
2. Audit each locality page for unique local evidence. Consolidate or noindex pages that only swap a locality name while sending users to the same Kothanur facility.
3. Add an About/Trust page with ownership, responsible contact, service limits, last-reviewed date and verifiable facility details.
4. Review every medical, staffing, response-time, equipment, pricing, hospital-tie-up and availability claim against current business records.

## 8–30 days: close competitor proof gaps

1. Create a service comparison hub covering residential care, home nursing, dementia, rehabilitation and palliative support.
2. Add a real facility page with address, map, access instructions, visit process, room types, current capacity status and original photographs.
3. Publish a caregiver standards page: recruitment, identity checks, training, supervision, replacement and escalation process.
4. Add author/reviewer attribution and review dates to health guides; cite authoritative medical sources when giving general health information.
5. Complete Google Business Profile categories, services, hours, photos, NAP and enquiry links. Request genuine reviews without incentives or fabricated counts.

## 31–90 days: build sustainable authority

1. Publish one original, first-hand guide per real family question, with interviews, checklists, local facility details or anonymised process evidence.
2. Earn local links and mentions through hospitals, community organisations, senior groups, caregiver education and relevant directories.
3. Add unique locality content only where service coverage is real; include local hospitals, routes, response constraints and a useful local checklist.
4. Create a monthly Search Console dashboard for impressions, CTR, indexed URLs, canonical selection, queries, local clicks and conversions.
5. Run monthly Lighthouse/field-CWV checks and optimise the largest content element, JavaScript execution, image delivery and caching based on measured evidence.

## Acceptance criteria

- Zero unsupported rating, ranking or “best” claims unless backed by a current, reviewable source.
- Every indexable locality page has unique local value and a distinct purpose.
- Search Console reports the intended canonical domain and no manual action.
- Core Web Vitals pass at the 75th percentile or have an active measured remediation plan.
- Each core service page identifies who the service is for, what is included, limitations, contact path and review date.
